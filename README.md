# Мой бюджет — новая версия интерфейса

## Что изменено
- Интерфейс полностью пересобран в виде раскрытого кожаного планировщика на кольцах.
- Разделы переключаются как страницы блокнота.
- Категории накоплений показаны отдельными коричневыми конвертами с клапанами и печатями.
- Нажатие на конверт открывает его карточку с планом пополнения и отметкой.
- На обложке размещены только согласованные надписи: MONEY CHOSE ME, MONEY TALKS, 888.
- Адаптивная компоновка для телефона и компьютера.
- Сохранены суммы и месяцы А/Б из предыдущей версии.
- Добавлена миграция отметок из localStorage предыдущей версии.

## Публикация на GitHub Pages
Замените файлы в корне репозитория файлами из этого архива, затем нажмите Commit changes. GitHub Pages обновит сайт автоматически.

## Важно о сохранении
Сейчас отметки сохраняются в localStorage конкретного браузера. В разделе «История» есть экспорт и импорт JSON-копии. Firebase/облачная синхронизация пока не подключены. Перед обновлением сайта скачайте резервную копию из старой версии, если там уже есть важные отметки. Новая версия пытается перенести данные автоматически, если старый localStorage доступен в том же браузере и на том же домене.
