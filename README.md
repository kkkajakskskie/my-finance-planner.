# Мой бюджет — личный органайзер

Стартовая версия в эстетике винтажного кожаного binder planner.

## Уже работает
- вкладки «Распределение», «Цели», «История», «Календарь»;
- месяцы А/Б и стартовые суммы;
- отметки галочками, автоматическое локальное сохранение;
- изменение ежемесячного дохода;
- экспорт и импорт JSON-резервной копии;
- адаптивный дизайн и декоративный открывающийся конверт.

## Важно
На этом этапе данные хранятся в браузере на устройстве. Это не облачная синхронизация. Перед очисткой браузера или переносом на другое устройство скачай копию в разделе «История». Следующий этап — подключить Firebase Authentication и Firestore с правилами доступа.

## Публикация через GitHub Pages
1. Создай новый репозиторий GitHub.
2. Загрузи `index.html`, `app.js`, `manifest.webmanifest` и `README.md` в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` → `/root` → Save.
4. Открой ссылку, которую покажет GitHub Pages.
